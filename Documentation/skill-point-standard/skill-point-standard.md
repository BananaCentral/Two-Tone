# Two-Tone Skill Point Standard

## Purpose

This standard defines how the party's shared Skill Points are gained, spent, and capped.

## SP Pool

- The party shares one SP pool.
- A battle starts with 3 SP.
- The base SP cap is 5.
- Multiple SP-cap increases stack additively.
- Dawn's Resourceful passive adds 2 to the party cap and starts that battle with 5 SP instead of 3. At the default cap, the party can hold 7 SP.

## SP Gains and Costs

- Every allied Basic Attack restores 1 party SP by default.
- A Skill usually costs 1 SP.
- A Skill cannot be used if the party lacks the required SP, unless a rule explicitly allows it.
- SP gains stop at the current cap by default. A rule may explicitly allow a gain to exceed it.
- Ultimates usually do not change SP. An Ultimate may grant or restore SP if its rule says so.

## Cap Changes

- If the cap decreases below the party's current SP, the excess SP remains until spent.
- New SP gains follow the current cap unless a rule explicitly allows otherwise.

## Exceptions

An ability may override this default only when its rules explicitly state a different SP gain. Enemy Basic Attacks do not restore party SP.
