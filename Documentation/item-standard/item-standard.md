# Two-Tone Item Standard

The player-facing item collection is named **Inventory**. It displays every item type, including Rune pieces, in one shared grid rather than category panels. Cards follow the shared [UI Layout Standard](../project-standard/ui-layout-standard.md): consistent sizes, centered artwork, concise labels, useful values, and owned quantities.

## Enchanted Bottles

Enchanted Bottles grant Character XP when used on a selected character:

| Item | Character XP granted |
|---|---:|
| Small Enchanted Bottle | 10 |
| Medium Enchanted Bottle | 100 |
| Large Enchanted Bottle | 1,000 |

Enchanted Bottles can be acquired from Challenges and lotteries. A Common character-lottery drop awards a bundle of five Large Enchanted Bottles. Players cannot buy them directly from the Store.

Bottle artwork uses blue for Small, purple for Medium, and gold for Large.

## Enchanted Books

Enchanted Books grant Weapon XP when used on a selected weapon:

| Item | Weapon XP granted |
|---|---:|
| Small Enchanted Book | 10 |
| Medium Enchanted Book | 100 |
| Large Enchanted Book | 1,000 |

Enchanted Books can be acquired from Challenges and lotteries. A Common premium-weapon-lottery drop awards a bundle of five Large Enchanted Books. Players cannot buy them directly from the Store.

Book artwork uses blue for Small, purple for Medium, and gold for Large.

Character XP and Weapon XP use the progressions in the [Character Level Standard](../character-level-standard/character-level-standard.md) and [Weapon Level Standard](../weapon-level-standard/weapon-level-standard.md). Items cannot advance a character or weapon beyond its current level cap.

## Runes

Runes are individual pieces belonging to one of the nine Rune Sets. They are obtained through Challenges. Challenge content and Rune reward rules are not configured yet. Each character may equip up to four owned Runes, all from the selected set. Equipping a Rune moves it from inventory to a loadout slot; removing it or changing sets returns it to inventory. A four-piece set activates its fixed set effect. Each equipped Rune can be leveled with a Core and customized with one main stat and three distinct substats.

## Cores

A Core is a shared upgrade material that can raise the level of one Rune or one Celestial by one level. One Core is consumed per level increase. Cores can be obtained from Rare lottery drops, Events, Story, and Game Modes. Rune Set effects are defined in the [Rune Set Standard](../rune-standard/rune-standard.md).

The soul-flame artwork represents a Core; the faceted crystal artwork represents a Gem.

## Gems

A Gem is an Ascension material for a character or weapon. One Gem is required for each Ascension. Gems can be obtained from Rare lottery drops, Events, Story, and Game Modes. Character and weapon Ascension gates are defined by their respective progression standards.
