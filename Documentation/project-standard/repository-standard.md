# Two-Tone Repository Standard

## Branch

- Work directly on the `prototype` branch.
- Do not create a task branch unless the user requests one.

## Versioning

- Format commit titles as `<Branch>: v<version>`, such as `Prototype: v0.0.0`.
- A major update increments the first number; a minor update increments the second; a small update increments the third.
- Only the user may designate an update as major or minor. Otherwise, treat it as a small update.

## Commit Message Body

- After the title, add a blank line.
- Use a category heading followed by bullets describing the changes.
- Use a separate heading for each affected category.

## Committing and Pushing

- Create a commit only after the user approves the general addition.
- Commit the completed addition to `prototype`, including only changes related to that addition.
- Do not push commits to GitHub; the user handles pushes manually.
