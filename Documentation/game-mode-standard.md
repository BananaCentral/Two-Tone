# Game Mode Standard

## Regular Mode

Regular Mode is the only mode currently available to players. See the [Account and Player Data Standard](account-and-player-data-standard.md) for the starting profile, sign-in, persistence, and rules for progress changes.

## Developer Access

Dev Mode is disabled until server-side developer roles are configured. Its authorization and profile isolation rules are defined in the [Account and Player Data Standard](account-and-player-data-standard.md#regular-and-dev-mode).
