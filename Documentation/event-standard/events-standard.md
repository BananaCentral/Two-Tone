# Events Standard

Open Events from the main menu. Give each event a stable ID and one of two types.

| Type | Availability |
|---|---|
| Limited | Active for a defined window. A recurring limited event opens a new window on its schedule. |
| Permanent | Available indefinitely. Claim progress persists on the signed-in account. |

Use the left tab rail defined in the [UI Layout Standard](../project-standard/ui-layout-standard.md). Show each event's name and type on its tab. Open [Login Event](login-event-standard.md) by default. Keep copy consistent with the [UI Copy Standard](../project-standard/ui-copy-standard.md).

## Soul’s Gift

Soul’s Gift is a permanent event. Use Soul’s character artwork as the focus of the banner, with Soulbound as supporting art. Place the five rewards in equal cards beneath the banner.

| Reward | Quantity |
|---|---:|
| Coins | 2,000 |
| Small Enchanted Books | 200 |
| Small Enchanted Bottles | 200 |
| Gems | 2 |
| Cores | 2 |

Grant all five rewards in one manual claim per account. Show **Claimed** after a successful claim and keep the banner and reward cards visible. Permanent events have no countdown.

The authenticated action grants the rewards and records the event ID under the same profile lock. Successful retries use the existing action receipt. Profiles created before the event can claim it once.
