# Two-Tone Party Standard

## Purpose

This standard defines the rules for the player's party: which characters belong to it, how the party is changed, and how it is represented in the overworld.

## Party Rules

- The player chooses which characters belong to the current party.
- A party contains at least one and no more than five characters.
- The same character cannot occupy more than one party slot.
- The game has one current party. Players cannot save or switch between multiple party presets.
- Players change party membership from a menu while in the overworld.
- Party membership cannot be changed during combat.
- Party order has no special meaning.
- In the overworld, only the selected character is shown. Other party members do not appear alongside them.
